About NetCheck

A browser-based network diagnostics toolkit. No installs, no accounts, nothing leaves your device except the checks themselves

What is NetCheck?

NetCheck runs a set of network and privacy diagnostics directly in your browser: your DNS resolver, its security posture, and the real recursion path your traffic takes, real-world download/upload speed and bufferbloat, how well your ad/tracker blocker performs, and the security headers of any site you point it at. Every test runs client-side against Cloudflare's edge network. There's no backend collecting your results.

Privacy

All checks run in your browser. Snapshots and adblock history are saved only to your device's local storage, never uploaded anywhere. Export creates a Markdown or PDF file on your machine. Nothing is sent to a server.

DNS Check

Detects your IP, resolvers, and PoP; traces your real recursion path via an in-site probe nameserver, probes 8 public resolvers over encrypted DNS, and flags missing DNSSEC, ECS subnet leaks, unencrypted DNS, WebRTC leaks, and malware filtering gaps, with fixes for each.

Speed Test

Measures download, upload, latency, jitter, and bufferbloat against Cloudflare's edge, Cloudflare Speed Test, Netflix Fast.com, Ookla Speedtest, or a custom server with memory-efficient streaming.

Ad Block Test

Runs 30+ tests across 7 categories with weighted scoring, detects filter lists, identifies which blocker you're running, and tests any custom URL.

Security Headers

Scans any URL's HTTP response headers with multi-hop, rate-limited SSRF validation and grades protection against XSS, clickjacking, and MIME sniffing.
