Key Decision: No Framework

Keeping vanilla TypeScript with a thin reactive layer. No React, no Preact, no Lit. Here's why:

Why No Framework?
  • Zero bundle size increase
  • No supply chain dependencies
  • Fits Cloudflare Workers constraints
  • Current code already works — don't burn it down
  • Observable pattern adds ~100 LOC total
What We Add Instead
  • observable.ts — tiny pub/sub reactive primitive
  • createState() — wraps data + subscribers
  • derive() — computed values from other state
  • auto-render — UI re-renders when state changes
  • Familiar mental model, no learning curve
