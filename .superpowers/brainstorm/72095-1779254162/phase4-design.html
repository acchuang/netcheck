PWA & Offline Improvements

Enhanced service worker — cache-first for static assets, network-first for API calls, stale-while-revalidate for results. Offline page shows cached last-known results with timestamps.

Install prompt — custom "Add to Home Screen" banner with one-tap install instead of browser's default prompt. Includes brief explanation of offline benefits.

Background sync — queue failed analytics pings for retry when connection is restored.

Notifications — optional push notification when continuous monitoring detects significant speed changes (opt-in only, privacy-first).
